# Security Policy

## Reporting

Report security issues privately via GitHub Security Advisories or repository issues marked sensitive.

## Scope

- MCP server input validation
- Guardrail bypass vulnerabilities
- Private key / seed phrase exposure in skills or examples
- Compliance screening false negatives

## Out of Scope

- Smart contract vulnerabilities in third-party protocols (use skill-08-security-audit)
- General blockchain network attacks

Never commit `.env` files or API keys.
