# Installing VS Code and JetBrains Plugins

## VS Code / Cursor / Windsurf

1. Download `.vsix` from [GitHub Releases](https://github.com/vaquarkhan/web3-agent-skills/releases) or install from Marketplace
2. Command Palette → **Extensions: Install from VSIX...**
3. Reload editor
4. Command Palette → **Web3 Agent Skills: Install Full Toolkit**

## JetBrains

1. Download `.zip` from Releases or install from JetBrains Marketplace
2. Settings → Plugins → Install from Disk
3. Restart IDE
4. Tools → Web3 Agent Skills → Install Full Toolkit

## Script Alternative

```bash
git clone https://github.com/vaquarkhan/web3-agent-skills.git
./bootstrap.sh /path/to/your/project
```

See [docs/jetbrains-setup.md](../docs/jetbrains-setup.md) and [docs/cursor-setup.md](../docs/cursor-setup.md).
