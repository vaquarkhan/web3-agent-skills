# SEC Howey Test

**Jurisdiction:** United States  
**Framework:** Investment contract analysis (SEC v. W.J. Howey Co., 1946)

## Four Prongs (ALL must be met for security classification)

1. **Investment of money** — Includes crypto, fiat, or other assets
2. **Common enterprise** — Horizontal (pooling) or vertical (promoter dependency)
3. **Expectation of profits** — Reasonable expectation of financial return
4. **Efforts of others** — Profits derived primarily from managerial/development efforts of others

## Implications

If classified as security:
- Must register with SEC or qualify for exemption (Reg D, Reg S, Reg A+)
- Cannot be offered to US persons without compliance
- Marketing materials are regulated

## Agent Actions

- Document Howey analysis for token launches targeting US
- Flag tokens with staking yield marketed as "returns"
- Escalate to legal counsel for borderline cases
- Never advise circumventing SEC registration

## Safe Harbors (Non-Security Indicators)

- Sufficiently decentralized ( Hinman speech factors)
- Pure utility with no profit expectation
- Consumptive use at time of sale
