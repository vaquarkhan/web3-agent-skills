# MiCA (Markets in Crypto-Assets Regulation)

**Jurisdiction:** European Union  
**Effective:** June 2024 (phased)

## Token Classifications

| Category | Description | Key Requirements |
|----------|-------------|------------------|
| EMT | E-Money Token (fiat-pegged) | 1:1 reserve, redemption rights |
| ART | Asset-Referenced Token | Diversified reserve, whitepaper |
| Other crypto-asset | Default category | Whitepaper notification, CASP license |
| Utility token | Access to good/service | Exempt if no investment expectation |

## CASP (Crypto-Asset Service Provider)

Requires authorization for:
- Custody and administration
- Trading platform operation
- Exchange of crypto for fiat/crypto
- Order execution
- Placement
- Advice and portfolio management
- Transfer services

## Whitepaper Requirements

- Issuer identity and governance
- Token rights and obligations
- Underlying technology risks
- Environmental impact (PoW disclosure)
