# ERC-6551 Token Bound Accounts

NFTs that own their own smart contract wallet.

Registry (Ethereum): `0x000000006551c19487814617e58FBCEC7b2aCa823`

Create account: `createAccount(implementation, chainId, tokenContract, tokenId, salt, initData)`

Enables NFTs to hold assets and execute transactions via ERC-1271 signatures.
